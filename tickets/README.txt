【tickets/ 文件夹使用说明 —— 子目录分类 + App 内筛选】

目标：把机票 / 酒店 / 火车 / 门票等 PDF 按「子目录」区分类别，一次导入手机即可离线查看，
并在 App 的 🎫 票夹 Tab 里按「日期」或「类别」两种入口查询。

────────────────────────────────
目录结构（关键：子目录名 = 类别）
────────────────────────────────
tickets/
├─ hotel/         → 类别「酒店 🏨」   例如 (9.23-9.26)Hotel Rott Prague.pdf
├─ restaurant/    → 类别「餐厅 🍽️」  例如 (9.26)Restaurant-Krčma Šatlava.pdf
├─ spot/          → 类别「景点 🎟️」  例如 (10.3)tickets_goldenhall.pdf
└─ traffic/       → 类别「交通 🚦」  例如 (9.27)ck Shuffle.pdf、(10.2)Budapest-Vienna.pdf

脚本 batch_embed_pdfs.js 会：
  1) 扫描每个子目录，用目录名映射到类别（hotel→酒店 / restaurant→餐厅 / spot→景点 / traffic→交通）；
  2) 解析文件名里的 (月.日[-月.日]) 前缀，自动归到对应日期（跨天住宿用 dateRange 在覆盖的每天显示）；
  3) 把 PDF 转 base64 内嵌进 trip-data.json 的 tickets 字段。

────────────────────────────────
命名规则
────────────────────────────────
文件名用「(月.日[-月.日])描述.pdf」格式，脚本会解析括号里的日期自动归类：
  - (9.23-9.26)Hotel Rott Prague.pdf  → 归到 9/23，并在 9/23~9/26 每天都显示（跨天住宿）
  - (9.27)ck Shuffle.pdf              → 归到 9/27（单天，只写一天即可）
  - 中英版机票行程单.pdf               → 无日期前缀，自动归入行程首日（建议也加上 (9.23)）

类别完全由「所在子目录」决定，文件名关键词不再参与类别判断。

────────────────────────────────
操作（电脑端，一次搞定）
────────────────────────────────
1. 把 PDF 按上面的子目录结构放好（没有的子目录自己建一个即可）。
2. 在 trip-data.json 所在目录运行：  node batch_embed_pdfs.js
   → 脚本扫描所有子目录 PDF，转 base64 内嵌进 trip-data.json 的 tickets，并按子目录类别 + 文件日期归类。
3. 把生成的 trip-data.json 传到手机（AirDrop / 微信文件 / 邮件均可），
   在 App 设置里「导入 JSON」即可。

────────────────────────────────
App 内怎么查（🎫 票夹 Tab）
────────────────────────────────
- 顶部「日期栏」：点某天 → 只显示当天凭证（含跨天住宿那天也显示）。
- 日期栏下方「分类筛选 chips」：全部 All / 🏨 酒店 / 🍽️ 餐厅 / 🎟️ 景点 / 🚦 交通。
  点某个类别 → 列出该类别的全部文件（跨天、每项带日期徽章），方便集中查看某一类凭证。
- 点「📂 打开」全屏看 PDF（内嵌，离线可用）；✏️ 编辑、🗑️ 删除、＋ 新增都在 App 内完成。
- 「预订提醒 · Bookings」仅在「全部」日期视图下显示。

────────────────────────────────
隐私与安全
────────────────────────────────
- 内嵌后 PDF 只存在你手机浏览器 localStorage，不上传任何服务器。
- 传输 trip-data.json 建议用 AirDrop / 本地发送给自己，避免公开发群聊。
- 导出当前数据（设置页）会含内嵌 PDF，可用于备份。
